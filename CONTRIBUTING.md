# Contributing

Thanks for helping travelers find reliable information, wherever they are going!

## What belongs here

- **Official sources first.** Government portals, national park offices, state transport operators and official tourism boards.
- **Genuinely useful, well-known resources.** Established apps, guides and references that many travelers rely on.
- **No look-alike or agent sites** for visas, travel authorizations (ETA, ESTA, eTA, ETIAS) or arrival cards. These often overcharge travelers or are outright scams.
- **No affiliate or tracking links.**

## How to add a link

1. Fork this repository and edit `README.md`.
2. Add your link to the most relevant section, using this format:

   ```markdown
   - [Name](https://example.com) - Short description ending with a period.
   ```

3. Keep descriptions short, factual and in English. Global resources go in `README.md`; country-specific ones go in that country's guide.
4. Make sure the link works and points to the original source.
5. Open a pull request explaining why the resource is useful.

## Adding a country guide

1. Copy `countries/indonesia.md` as a template and name the file after the country, e.g. `countries/japan.md`.
2. Keep the same section order where it applies: entry and visas, official tourism information, getting around, parks and permits, safety, emergency numbers, money.
3. Add the country to the **Country Guides** section of `README.md`, in alphabetical order.

## Reporting outdated information

Entry rules, fees and park openings change often. If something is out of date, please [open an issue](../../issues/new/choose) with a link to the official source that shows the change.

## Code of conduct

Be kind and constructive. Contributions are reviewed by the maintainers at [Weltur](https://www.weltur.com).
